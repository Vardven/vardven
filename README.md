## 📝 常用 Git 基础命令
- `git init`：初始化本地仓库，开启版本控制
- `git add`：将改动文件加入暂存区，等待提交
- `git commit`：把暂存内容正式保存到版本历史，附带提交说明
- `git status`：查看工作区与暂存区文件变动状态
- `git checkout`：切换仓库历史不同版本、分支或文件状态
